# Undo–Redo Text Editor Using Data Structures

## 📌 Project Overview
The **Undo–Redo Text Editor** is a console-based application developed in **C++** that demonstrates the real-time implementation of **Data Structures**, mainly **Stacks**, to perform undo and redo operations efficiently.

This project simulates the working of basic text editors where users can type text, delete text, undo previous actions, redo reverted actions, and save their work using file handling.

---

## 🎯 Objectives
- To understand practical implementation of **Stacks**
- To perform **Undo** and **Redo** operations using data structures
- To develop a menu-driven text editor using **C++**
- To demonstrate file handling operations
- To improve programming and problem-solving skills

---

## 🛠️ Technologies Used
- **C++**
- **Stacks**
- **File Handling**
- **Object-Oriented Programming**
- **Console Application**

---

## ⚙️ Features
- Add text to document
- Delete text
- Undo last action
- Redo previous action
- Display current document
- Save text into file
- Open existing file
- Menu-driven interface

---

## 🧠 Data Structures Used

### Stack
Two stacks are used:

1. **Undo Stack**
   - Stores previous states/actions
   - Used to reverse latest changes

2. **Redo Stack**
   - Stores undone actions
   - Used to restore reversed actions
